# 共享执行后端：设计与验证

## 执行所有权

```mermaid
flowchart LR
  D[桌面原插件0.6.0] --> G[Mac loopback Gateway]
  P[手机或电脑浏览器] --> T[VS Code Tunnel]
  T --> R[远程attach插件0.6.100]
  R --> G
  G --> S[同一会话与执行进程]
```

浏览器本身不直接访问Mac loopback端口；远程扩展运行在同一Mac，沿已有隧道接收UI消息。Gateway不暴露到公网。

私有0600连接描述只保存workspace和可选preferredPid。连接发现验证同用户桌面0.6.0进程、loopback监听、对应启动日志和实际认证RPC。启动token只在连接时进入内存，不保存到描述文件、设置或文档。旧日志可能来自仍运行的老窗口，不能只看最新run；端口复用也不能代替认证。多个owner歧义时失败关闭，不随意选取，不退回启动竞争后端。

## attach副作用边界

attach不启动/停止owner，不迁移profile，不seed插件，不自动清理/隔离/合并工作树，不重复生成标题，不因为切换对话自动归档空草稿。profile与密钥修改入口在服务层拒绝，UI只读。消息、队列、取消与审批仍走共享Gateway原接口，由同一backend处理。

## 验证

- 原套件加回归：627通过、18跳过；类型检查、生产构建通过。
- 实际隔离Gateway + fake模型：两端同时接收流式输出；一端断开另一端继续；重连snapshot恢复；从两端各发一轮，每轮一次模型调用。
- 回归覆盖私有描述、workspace校验、无owner拒绝、stop/发现并发、端口复用旧token、服务连接切换、无重复自动合并、既有会话续聊不换ID、配置/credential写保护、新建会话不重复隔离、浏览不自动归档。
- 用户实测手机刷新后确认状态与进度同步；宿主日志证实附着原桌面owner、无新子runtime。
- 原上游全库lint已有54个错误，逐文件基线比对相同；新增实现专项lint通过，不宣称全库lint通过。

尚未全量验收：业务会话手机实际发出下一条消息、多个客户端同时审批、真实桌面重启跨PID恢复、休眠与长时断网。连接重发现有单元覆盖，不替代真实重启验收。不要把共享历史、transport smoke或安装成功上推为全部业务验收。

## 维护

上游升级可能改变日志格式、协议与历史格式。本发布固定原0.6.0与DSH0.1.5-alpha.1，不能自动套用到0.6.1/V4。源码保留上游Git历史和MIT许可；原发布工作流仅允许在上游仓库执行，避免本分支自动发布未经验证的多平台包。新版本先在隔离profile回归，再发布独立tag/校验值。

公开分发源码重新运行原627项测试（18跳过）、类型检查及布局助手3项测试通过；272个runtime/build/test文件与已安装定制版工作区逐字节一致，VSIX入口与原构建一致。分发仓库未引入运行行为变更。
